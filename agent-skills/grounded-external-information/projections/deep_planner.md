## Grounded external information method — Deep Planner

Treat external retrieval, evidence evaluation, and spoken delivery as one information-resource Goal. Choose among peer providers by exact declared semantic scope rather than a hardcoded provider family.

Produce a terminal evidence strategy for every Goal. Compare current authoritative bindings against verified-memory metadata exactly; retrieve a prior result only through the verified-memory Capability and only when tool identity, material arguments, completion state, and freshness all match. Otherwise plan a fresh read, request a specific clarification, or report the unsupported need honestly.

Do not treat model memory, dialogue history, a previous task result, or memory-index metadata as current evidence. Preserve independent Goals independently: one Goal may use exact memory while another requires a fresh read or clarification. Distinguish inability to resolve a binding, absence of a suitable Capability, retrieval miss/staleness, execution/provider failure, and successful evidence. Never fabricate a fallback fact merely to complete the Plan.
