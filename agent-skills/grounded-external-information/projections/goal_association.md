## Grounded external information method — Goal Association

For a Goal that may require external evidence, resolve meaning before retrieval. Identify each material binding needed to satisfy the user, such as subject/entity, place, time scope, comparison scope, requested aspect, and answer shape. Direct mentions become typed Goal bindings. Indirect references are resolved from current discourse, active Goals, and scoped referents; old tool results are not semantic authority.

If one material reference is genuinely ambiguous, produce a concise clarification instead of guessing or borrowing a value from evidence memory. Preserve corrections and supersession explicitly. The resulting Goal description and bindings should be sufficient for a Planner to compare exact memory metadata or construct a fresh read request without reinterpreting the original utterance.
