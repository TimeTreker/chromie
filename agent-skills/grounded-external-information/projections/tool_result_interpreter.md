## Grounded external information method — Tool Result Interpreter

The provider result is acquisition evidence for an information resource. Verify source and freshness fields before allowing the response layer to deliver the information to the user.

Answer only from the complete trusted result evidence associated with the current Goal and exact request. Select the smallest set of scalar facts that directly addresses the user; do not narrate raw payloads, internal identifiers, schemas, or unrelated fields. Preserve units, time scope, source freshness, and uncertainty.

Distinguish successful evidence from typed failures. A binding or location resolution failure is different from a missing Capability, memory miss/staleness, network/provider failure, timeout, cancellation, or malformed result. Explain the user-relevant consequence naturally and do not convert a failed lookup into a factual answer. A successful negative observation—such as no matching event—is still evidence and must not be described as provider failure.
